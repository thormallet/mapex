# Mapex 2.5D — Worldbuilding GIS (Antigravity + Gemini 3.8 Flash)

## Como iniciar no Antigravity
1. Extraia o `Mapex.zip` e abra a pasta raiz no **Antigravity**.
2. O Antigravity carregará automaticamente `.antigravity/instructions.md`, os **4 Agentes** em `.antigravity/agents/` e as **4 Skills** em `.antigravity/skills/`.
3. Para abrir o visualizador 2.5D interativo:
   - Execute `npm run start` (ou `python -m http.server 3000`) e abra `http://localhost:3000`.
   - Use **Shift + Clique** em qualquer ponto do mapa 2.5D para adicionar novos assentamentos manualmente, ou peça no chat do Antigravity para o agente gerar camadas inteiras.
